# DuoArena V5 Frontend

Это полный frontend replacement поверх V4 backend.

Что поменялось:
- основной шрифт: Manrope;
- крупнее весь UI;
- нормальные размеры текста вместо микрошрифта;
- новый hero;
- новая карточка профиля;
- карточки режимов полностью переделаны;
- login screen переделан;
- lobby/game/stats увеличены и упрощены;
- light/dark/system и RU/EN сохранены;
- Google / GitHub / Guest сохранены;
- backend V4 менять не требуется.

## Установка

Заменить папки `templates/` и `static/` содержимым архива.

После этого:

```bash
git add templates static
git commit -m "DuoArena V5 frontend redesign"
git push origin main
```

Render сам передеплоится.
